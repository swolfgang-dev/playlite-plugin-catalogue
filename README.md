# Playlite plugin catalogue

`catalogue.json` lists independent distribution repositories. Playlite checks repository visibility and release availability before displaying a plugin. Making an individual distribution repository private hides it from anonymous clients without changing this catalogue.

Packages are attached to releases in the individual repositories; this catalogue does not mirror them. Existing downloads cannot be revoked by changing visibility.
